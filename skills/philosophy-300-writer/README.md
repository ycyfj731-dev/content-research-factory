# Philosophy 300 Writer

Course-level writing controller for **《西方哲学，从0开始》**.

It connects three layers:

```
complex-to-clear
        ↓
philosophy-300-writer
        ↓
editorial publishing / visual system
```

## Responsibilities

This skill owns:
- source-layer discipline;
- lesson question discipline;
- canonical-core preservation;
- zero-baseline philosophy writing;
- anti-repetition / anti-AI prose;
- lesson closure;
- source-page selection;
- approved-prose freezing;
- surgical revisions.

It does **not** own final visual layout.

## Default production rule

No lesson goes directly from title to polished prose.

First establish:
question → source layer → canonical core → must-not-say → stop point → beginner bottleneck.

Then write.

## Editing rule

If a paragraph has already been approved, leave it alone unless the requested correction actually touches it.
