# Philosophy 300 — Freeze & Revision Policy v0.1

## Frozen layers

The course uses layered freezing.

### Layer 1 — Canonical core
Freezes what the lesson means.

Changes require:
- explicit revision;
- source review;
- version increment;
- distortion-gate rerun.

### Layer 2 — Approved prose
Freezes exact wording once explicitly approved by the user/editor.

Changes default to surgical repair only.

### Layer 3 — Sources
Freezes the public source set for an approved lesson.

Change only when:
- a source is corrected;
- a stronger source is substituted;
- the lesson itself changed.

### Layer 4 — Visual treatment
Downstream from prose.

Visual work may change:
- pagination;
- line breaks;
- hierarchy;
- type scale;
- image placement;
- whitespace.

It may not silently change approved prose.

---

## Surgical revision

Local issue → local change.

Examples:
- awkward sentence → sentence only;
- confusing paragraph → paragraph only;
- weak transition → transition only;
- repeated section → section only.

Never use a local comment as permission for a full rewrite.

---

## Wider revision allowed only when

- central question changed;
- canonical core changed;
- lesson structure is internally broken;
- local repair creates contradiction;
- source discovery invalidates the current framing.

Record the reason.

---

## Versioning

Meaning/source framing change:
- increment content/core version.

Pure typo/punctuation correction:
- patch-level note is sufficient.

Visual-only change:
- visual version only.

Never hide a meaning change inside a style revision.
