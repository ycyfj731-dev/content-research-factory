# Philosophy 300 — Source Discipline v0.1

## Source hierarchy

### A. Primary / surviving ancient evidence
Use when available:
- surviving fragments;
- direct works;
- dialogue passages;
- poems;
- speeches;
- inscriptions where relevant.

### B. Ancient testimony
Use when the original work is lost or incomplete.

Always identify that the report is later.

### C. Modern scholarship
Use to:
- reconstruct incomplete evidence;
- explain disputes;
- identify retrospective categories;
- check historiographical assumptions.

### D. Course bridge
A pedagogical question used by the course.

Never attribute a course bridge to the historical thinker.

---

## Required distinctions

Keep separate:
- direct quote vs paraphrase;
- original fragment vs later paraphrase;
- thinker vs later commentator;
- ancient report vs modern reconstruction;
- historical person vs literary character;
- current scholarly consensus vs contested reading.

---

## Current-source rule

For living reference resources, prefer the current official page.

Do not cite an old archive merely because it appeared in an earlier search.

If date matters, distinguish:
- page/edition date;
- last substantive revision.

---

## Famous-quote rule

A famous phrase is not automatically authentic.

Before presenting it as a quote:
1. locate the earliest surviving source;
2. verify wording;
3. determine whether it is direct, paraphrased, or later formulation.

If uncertain, use indirect speech.

---

## Motivation rule

Evidence that X held a view does not automatically tell us why X held it.

Write motive only when:
- the thinker states it;
- an ancient source credibly reports it;
- or modern reconstruction is explicitly labeled as reconstruction.

---

## Retrospective-category rule

Later philosophical vocabulary may help explain an earlier thinker, but must not be presented as the earlier thinker’s own explicit conceptual system without evidence.

Example:
Aristotle’s language of first principles may structure his report of Thales. That does not prove Thales himself formulated an Aristotelian theory of “principles”.
