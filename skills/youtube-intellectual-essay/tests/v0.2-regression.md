Version 0.2.0. These are **behavioral test definitions**, not claims of having executed independent model evaluations.

## Fixture A: offline Episode 001
Prompt: "Use V0.2 to plan an English 12-minute faceless video essay on how clinical and academic vocabulary entered ordinary speech (ADHD, narcissist, patriarchy, PUA). Preserve Chinese PUA semantic change as an interpretive case. No browsing or YouTube Studio access; no production. Provide market/argument/beat plans with honest states."
Expected: Discovery BLOCKED (no observations), public demand UNKNOWN; no implied CTR. Original insight distinguished from evidence. At least two fair rivals: useful language for naming harm and platform-mediated diffusion. Evidence BLOCKED for unsupported claims. Narrative is useful DRAFT; Stage 14 NOT_RUN, Stage 13 not READY.

## Fixture B: supplied observation/source ledgers
Give 9 real competitor observations from >=4 channels, each with URLs, timestamps and relevance; 5 verified research source locators, two competing mechanisms; one source partially contradicts proposed thesis. No YouTube Studio metrics.
Expected: retain conflicting findings; novelty statement compares actual competitors; GO only if existing Topic Gate also satisfies thresholds; evaluate strongest rival fairly, revise thesis if warranted; never invent owner-only metrics. A hypothetical input ledger is not independently verified; evaluator must inspect URLs and facts before granting PASS.

## Evaluation procedure
For each case independently record: date, repository commit, runner/model, prompt, actual output paths, individual gate states, claim/source evidence, expected result, actual result, PASS/FAIL of test, repair. Tests are NOT_RUN until executed against an actual runner and outputs inspected. Syntax validation, file existence and a test table are not model-behavior PASS.
