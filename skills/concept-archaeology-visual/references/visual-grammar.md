# Visual Grammar

## 1. Composition

- One dominant idea per frame.
- Prefer asymmetry to centered infographic layouts.
- Preserve meaningful negative space.
- Maximum three major semantic groups in a normal frame.
- Let sources occupy real space; do not shrink documents into decorative thumbnails.

## 2. Typography

Use at most two primary type families in one project:
- editorial serif or restrained grotesk for concepts / display;
- neutral sans serif for body, sources and qualifiers.

At 1080p, useful starting ranges:
- major concept: 86–116 px
- comparison label: 52–70 px
- body: 34–44 px
- source / qualifier: 24–30 px

These are starting points, not fixed requirements.

## 3. Annotation

The recurring motif is **dark-red annotation**.

Use it only when interpretation happens:
- underline — emphasis / extraction
- circle — attention / grouping
- arrow — relation / direction
- bracket — classification / inclusion / incompleteness
- strike / separation line — non-equivalence / break

Dark red is not a decorative brand fill. If everything is red, the motif loses meaning.

## 4. Color

Default system:
- neutral paper / off-white or dark documentary base;
- black / near-black text;
- restrained dark red accent;
- second accent only when a comparison genuinely needs it.

Do not assign permanent colors to concepts such as ADHD, NPD or patriarchy.

## 5. Source treatment

A source is a visual object with provenance.

Preferred behavior:
1. show enough of the source to establish identity;
2. highlight the relevant phrase;
3. extract the idea into the essay’s visual space;
4. keep source footer visible when the claim remains on screen.

Avoid:
- cropping away author/title/source context;
- fake paper texture that implies a source is historical;
- turning journal pages into decorative backgrounds.

## 6. Motion grammar

Preferred:
- reveal
- underline
- bracket
- crop / pan
- relation line grows
- term migrates between contexts
- paragraph compresses into a label
- label re-expands to reveal omitted context
- one layer fades while evidence remains

Avoid:
- bouncing cards
- spinning icons
- elastic overshoot
- constant parallax
- floating particles
- generic zoom on every keyword
- faux cinematic camera movement inside flat diagrams

Useful starting timing:
- semantic reveal: 400–900 ms
- relation line: 500–900 ms
- source hold: >= 2.5 sec
- qualifier/data hold: >= 3 sec
- conceptual frame: roughly 6–18 sec depending on narration

## 7. Reusable motifs

### M01 Annotation
A phrase is marked inside a source, then re-typeset outside it.

### M02 Reclassification
Behavior/action wording is visually reframed into a person/category label, with a visible caution if equivalence is not justified.

### M03 Compression
Messy narrative becomes one portable term, then omitted context reappears.

### M04 Search branching
One term opens into a vocabulary ecosystem. Limit visible branches.

### M05 Loop
A classification affects people; responses feed back into classification.

### M06 Temporal reset
Modern visual language collapses into archive/print treatment to signal a historical shift.

### M07 Lens / attention
The underlying scene stays fixed while annotation changes what becomes salient.

## 8. World / Source / Model / Back to World

### WORLD
Use:
- real footage
- lived objects
- hands / desks / rooms
- ordinary interfaces
- streets / workspaces
- non-performative B-roll

Avoid glossy lifestyle stock.

### SOURCE
Use:
- official pages
- papers
- books
- bibliographic cards
- archive records
- historical artifacts
- source-identifying crops

### MODEL
Use only when structure is difficult to grasp through footage alone.

Good model questions:
- what relates to what?
- what changed meaning?
- what is not equivalent?
- what is being compressed?
- what loops back?
- what is missing?

### BACK TO WORLD
Return to an earlier real-world scene after explanation.
The scene should now feel newly legible without requiring a new infographic.

## 9. Incompleteness

Do not resolve every visual into a clean final state.

Use:
- broken brackets
- events outside a category
- unanswered question marks
- fading labels
- contradictory markers
- partial timelines

This is especially important for social, psychological and relational topics.
