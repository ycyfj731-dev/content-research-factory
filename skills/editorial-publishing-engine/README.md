# Editorial Publishing Engine

出版级编辑排版引擎。把已批准长文转换为 1080×1440 的编辑型图片轮播。

## Philosophy 300 defaults

- frozen prose stays frozen;
- 5 masters: essay / statement / evidence / cover / credits;
- 6-column grid;
- white background, near-black text, red or gold single accent;
- regular target: 8–10 pages, normally no more than 10;
- fixed section markers: 01 / 02 / 03...;
- every page includes `@每天读一点哲学`;
- source page shows reader-facing sources only;
- internal production metadata stays in repo/audit, not on public pages;
- KNOW / CORRECT / TOOL / PERSON are internal QA dimensions, not mandatory standalone cards.

The engine is downstream of frozen prose. It may paginate and style; it may not silently rewrite the approved lesson.
