# Layout System — MASTER TEMPLATE SYSTEM v1.1

## Five masters

Every public page must declare exactly one:
- essay
- statement
- evidence
- cover
- credits

Essay is the default and must remain at least 50% of a normal deck.
Statement is tension, not default layout; maximum two pages and never used merely to make a page look different.
Evidence is for functional maps, documents, quotations, chronology, or comparison.
Cover appears once. Credits/source page appears once.

## Grid

Canvas: 1080×1440.
Global margin: 72.
Six-column grid.
Essay body width: 776.
Headline may use the full 936 measure.

## Section marker

Regular content pages use continuous two-digit Arabic markers:
`01 章节名`, `02 章节名`, etc.

- number: page accent, about 26px;
- title: near black, about 23px;
- spacing only; no middle dot;
- no return to lightweight 13px kicker;
- one deck, one marker style.

## Chrome

Every page:
- top left: PHILOSOPHY 300
- top right: NNN / 300
- bottom left: 《西方哲学，从0开始》 · @每天读一点哲学
- bottom right: NNN / 300 · PAGE NN

Chrome is publication identity and may not drift page to page.

## Pagination

Philosophy 300 regular target: 8–10 pages, normally not over 10.
If prose is dense, merge adjacent cognitive actions or improve page utilization.
Do not delete frozen reasoning simply to fit a page budget.

## Frontend / backend split

KNOW / CORRECT / TOOL / PERSON are internal lesson-value checks.
They are not mandatory public headings or standalone cards.
