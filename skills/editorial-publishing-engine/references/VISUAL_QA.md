# Visual QA v1.1

A deck fails visual QA if:
- page count exceeds 10 without explicit exception;
- account chrome is missing on any page;
- section markers skip or change format;
- essay body widths drift;
- statement pages become the dominant visual mode;
- source page shows internal engineering metadata;
- approved prose is silently dropped to fit layout;
- decorative images are added without information value;
- a backend lesson-value field becomes a forced public card;
- title line breaks feel mechanically even rather than semantically natural.

Human review should check:
1. Does the deck still feel like one publication?
2. Can every page be read without visual strain?
3. Does each page perform one main cognitive action?
4. Are the most dramatic layouts reserved for genuinely important moments?
5. Is the source page useful to a reader rather than to the production team?
