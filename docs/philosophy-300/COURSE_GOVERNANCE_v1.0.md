# Philosophy 300 — Course Governance v1.0

Status: **FROZEN BASELINE**

This document records which artifacts govern the course and what each one is allowed to change.

## Layer 1 — Historical / conceptual truth
Authoritative:
- `CANONICAL_CORES_001_030_v1.0.md`
- `SOURCE_SCREEN_001_010.md`
- `SOURCE_SCREEN_011_030.md`

- evidence status;
- attribution;
- boundaries;
- stop points.

## Layer 2 — Explanation method

- `skills/complex-to-clear/SKILL.md`

- distortion gate;

## Layer 3 — Philosophy course writing
Authoritative:
- `skills/philosophy-300-writer/SKILL.md`

This controls:
- lesson production workflow;
- anti-AI prose;
- anti-repetition;
- source-page discipline;
- surgical revision;
- exact lesson freeze handling.

## Layer 4 — Exact approved lesson prose
Example:
- `LECTURE_001_FINAL_FROZEN_v1.0.md`

An exact prose freeze outranks later style rewrites.

## Layer 5 — Visual publication
Visual systems are downstream.

They may never silently rewrite Layer 1–4.

## Conflict rule
When two layers conflict:
1. source fidelity wins over rhetoric;
2. frozen canonical core wins over stylistic preference;
3. exact approved prose wins over visual convenience;
4. local user feedback changes only the smallest relevant layer.

## No silent drift
Any meaning change requires:
- explicit reopening;
- source review if needed;
- version increment;
- rerun of relevant gates.

No content change may be hidden inside:
- copyediting;
- layout;
- social-media adaptation;
- shortening;
- visual redesign.
